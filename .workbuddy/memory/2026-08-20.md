**关键设计说明**：
- `artifacts_public` 是 `security_invoker = true` 视图，anon 直接读会被 RLS 屏蔽 → 服务端必须用 `service_role` 读视图；服务端的 service_role 读不到 `exact_*` 列（视图本身就没暴露）
- `artifacts` 表对 `authenticated` 没有 SELECT grant（只有 insert/update/delete），所以 `.insert().select()` 隐式 SELECT 会被拒——必须 insert 后用 service_role 单独读视图拿回数据
- 注册时 Supabase 默认开 email confirm 会触发邮件发送，超出 demo 反垃圾阈值；用 admin API 创建 `email_confirm: true` 跳过邮件验证是开发期友好的兜底
